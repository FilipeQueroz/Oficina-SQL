# SQL Essencial - Oficina de Banco de Dados

## Descrição:

A **Oficina de SQL** tem como objetivo apresentar os principais conceitos relacionados a bancos de dados e à linguagem SQL, começando pelos conceitos básicos e avançando para a realização de consultas e manipulação de dados.

Durante a oficina, os participantes terão contato com a estrutura básica de um banco de dados, aprendendo como os dados são organizados em tabelas e como realizar consultas e alterações utilizando comandos SQL.

A oficina também contará com exemplos e exercícios práticos, permitindo que os participantes acompanhem os conteúdos e pratiquem os comandos apresentados utilizando um banco de dados preparado para as atividades.

### Conteúdos abordados:

* Conceitos básicos de Banco de Dados;
* Introdução à linguagem SQL;
* Estrutura de tabelas, registros e colunas;
* Consultas utilizando `SELECT`;
* Filtros com `WHERE`;
* Ordenação com `ORDER BY`;
* Inserção, alteração e exclusão de dados;
* Introdução aos relacionamentos entre tabelas;
* Exercícios práticos.

A proposta da oficina é apresentar os fundamentos de SQL de forma simples e prática, proporcionando aos participantes uma base inicial para trabalhar com bancos de dados.
